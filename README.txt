LuckyTools iPhone PWA – Starterversion

Enthalten:
- Mobile Web-App-Oberfläche
- Auswahl lokaler APK-/IPA-Dateien
- Anzeige von Dateiname, Format, Dateigröße und SHA-256
- Offline-Grundgerüst (Service Worker)

Wichtig:
- Diese Version verändert keine Apps und umgeht keine Käufe/Lizenzen.
- iOS-Webseiten dürfen andere installierte Apps nicht auslesen oder patchen.
- Dateien werden in dieser Version nur im Browser verarbeitet und nicht hochgeladen.
- Analysen werden nur während der aktuellen Sitzung angezeigt.

So verwendest du sie:
1. ZIP entpacken.
2. Dateien auf einen HTTPS-Webhost hochladen (z.B. eigenen Webspace).
3. Die HTTPS-Adresse in Safari auf dem iPhone öffnen.
4. Teilen > Zum Home-Bildschirm.

Für eine installierbare native IPA brauchst du einen iOS-Build und Apple-Signierung.
